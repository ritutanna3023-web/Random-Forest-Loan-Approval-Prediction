# Random Forest Loan Approval Prediction

## About the Project

This is a beginner-level Machine Learning project that uses the Random Forest Classifier to predict loan approval based on applicant income, credit score, and loan amount.

## Algorithm Used

* Random Forest Classifier
* Ensemble Learning

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Dataset

This project uses a small sample dataset with the following features:

* Income: Applicant's income
* Credit_Score: Applicant's credit score
* Loan_Amount: Requested loan amount
* Approved: Loan approval status (0 = Rejected, 1 = Approved)

## Project Workflow

1. Import required libraries.
2. Create a sample loan dataset.
3. Separate input features and target.
4. Split the dataset into training and testing data.
5. Train a Random Forest Classifier.
6. Predict loan approval.
7. Evaluate the model using accuracy, classification report, and confusion matrix.
8. Visualize feature importance.
9. Predict the outcome for a new applicant.

## Installation

Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn jupyter
```

## How to Run

1. Clone or download this repository.
2. Open the notebook in Jupyter Notebook.
3. Run all cells in order.
4. Enter applicant details in the final cell to see a prediction.

* Understanding Random Forest Classification
